| Folder                 | Purpose                                                       |
| ---------------------- | ------------------------------------------------------------- |
| `components/`          | Reusable UI elements (buttons, cards, loaders)                |
| `features/`            | Logical grouping of features like complaints, auth, dashboard |
| `layout/`              | Page layout (Sidebar, Navbar, etc.)                           |
| `pages/`               | Route-level views rendered inside layout                      |
| `routes/`              | Handles role-based and protected routing                      |
| `services/`            | Centralized Axios setup with token headers                    |
| `context/` or `store/` | Global state for auth, roles (React Context or Redux)         |
