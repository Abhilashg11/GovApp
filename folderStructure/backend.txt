│   ├── services/          # Business logic (DB queries, external calls)

| Folder/File    | Description                                                  |
| -------------- | ------------------------------------------------------------ |
| `controllers/` | Logic to handle requests (calls services, returns response)  |
| `models/`      | Mongoose (MongoDB) or Sequelize (SQL) schemas                |
| `routes/`      | Express route declarations (`router.get(...)`)               |
| `middlewares/` | JWT/role checks, error catchers                              |
| `services/`    | Business logic (DB actions, cloud storage, AI service calls) |
| `utils/`       | Token creation, geo location utils, etc.                     |
| `config/`      | Central place for DB URL, Azure keys, Map API, etc.          |
| `uploads/`     | (optional) For storing files locally before pushing to Azure |
| `.env`         | Secrets like DB\_URI, JWT\_SECRET, AZURE\_KEY, etc.          |
